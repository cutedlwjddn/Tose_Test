금융 UI 데모 — 실제 금융 서비스와 연결되지 않는 가상 UI

1. 이 폴더의 파일을 그대로 HTTPS 정적 웹 호스팅에 올립니다. (예: GitHub Pages)
2. 아이폰 Safari에서 배포된 URL을 엽니다.
3. 공유 메뉴 → 홈 화면에 추가 → 추가. 웹 앱으로 열기 옵션이 보이면 활성화합니다.
4. 전체 → 설정 → 프로필 수정에서 테스트용 정보를 입력하고 저장합니다.
5. 전체 → 이름을 누르면 가상 프로필을 볼 수 있습니다.

개인정보는 브라우저 localStorage에만 보관됩니다. 실제 개인정보를 입력하지 마세요.
HTTPS 배포 후 첫 접속에 서비스 워커가 등록되면 오프라인 캐시가 준비됩니다.
HTML 파일 단독으로는 설치용 아이콘, 오프라인 기능이 보장되지 않습니다.
